Datos y respaldo

La web lee data/spx_daily.csv desde este repositorio. GitHub Actions descarga las velas diarias OHLC del índice ^GSPC mediante yfinance. El navegador no realiza peticiones a Yahoo ni Stooq.

La automatización se programa de lunes a viernes después del cierre de EE. UU. También puedes ejecutarla manualmente desde GitHub → Actions → Update SPX daily data → Run workflow. Yahoo Finance es una fuente no oficial y puede limitar el acceso.

VIX

El VIX no está conectado. ATR es volatilidad realizada, no volatilidad implícita.
